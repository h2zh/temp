# Crowd3D 画风（主题）说明

> 2026-10-22 起；2026-11-03 按决定 D29 改写。决定 D7 已由产品负责人拍板：画风由产品负责人定，所以把**测到的东西**和**长什么样**分开。决定 D29（产品负责人，2026-11-03）：放弃给模型上色，模型一律是素模。本文写给美术和设计：怎么加一个画风、画风文件里每个字段的意思、校验器检查什么。代码在 `web/themes.js`、`web/themes/*.json`、`web/stylized.js`；整体设计见 `docs/STYLIZED_MODEL.md`。

## 1. 原理：测到的和长什么样分开

- 风格化作业（`crowd3d/stylize.py`）只负责形状：地图轮廓、高度、照片量出的尺寸（D15、D24、D25），以及每个面的来源。
- 查看器按面的种类上色：屋顶用画风的 `clay.roof`，其余（墙、转角、屋顶切面、底面）都用 `clay.wall`，每个面都画一层淡淡的斜纹。GLB 里的材质颜色、贴图和 `locked` / `observed` 标记一律不用来上色（`observed` 只用来选第一眼朝向哪一侧），所以 D29 之前写的、带照片颜色的旧 GLB 也显示成素模（旧模型里贴在屋顶上的照片色块 `roof-patch` 不画，下面的屋顶面本来就是完整的）。
- 画风只决定这些面和线用什么颜色、什么光影画出来，改不了形状和来源卡片。
- 画风和网站的浅色 / 深色（D32，2026-11-05）互不相干：切换浅色 / 深色只换查看器的面板（标题、画风下拉框、来源卡片、图例、照片卡片和对照的工具栏），素模色、描边、光影、天空背景和墨色都不变；画风也不读浅色 / 深色的设置。所以画风的天空要自己保证画在上面的墨色标记看得清，不能指望页面换成深色。
- 链接不带 `theme` 参数时就是默认画风。默认画风的素模色就是 D29 之前素模墙显示的颜色（`clay.wall` #c8d1df，`clay.roof` #c9d2e2），描边、光影都没变：D29 前后同一个素模 GLB 的截图逐像素相同，只少了"待解锁"牌子和墙上的虚线框。

## 2. 怎么加一个画风

1. 复制 `web/themes/storybook.json`，改名为 `<id>.json`。id 只用小写字母、数字和连字符，和文件名一致。
2. 按第 3 节改字段。
3. 打开 `stylized.html?model=<模型>&theme=<id>` 就能看，不用改代码。
4. 要出现在面板的"画风"下拉框里，把 id 加进 `web/themes/index.json`。测试会检查目录里每个画风文件都列进去了。
5. 跑 `node --test 'web/tests/*.test.mjs'`：校验器（第 4 节）逐个检查 `web/themes` 里的画风。没通过校验的画风，查看器也会拒绝：退回默认画风，并在面板上写明原因。

## 3. 字段

颜色一律写成 `#rrggbb`，意思是"看到的颜色"（sRGB，打光之前）。

| 字段 | 必填 | 说明 |
|---|---|---|
| `id` | 是 | 和文件名一致 |
| `schema` | 是 | 现在是 `1` |
| `name` | 是 | 中文短名，显示在下拉框里（建议 ≤ 6 个字） |
| `description` | 是 | 一行中文，说清是什么画风 |
| `en` | 是 | 英文页面用的名称和描述（D32）：`{"name", "description"}`，各一行英文，不能带中文字符或全角标点；`name` 建议 ≤ 24 个字符（超过只警告）。例如 `dusk` 是 "Dusk gradient" |
| `ink` | 是 | 墨色：画在模型上面的标记用的线色（例如照片位置图层的计数气泡和北向标记） |
| `clay.wall` | 是 | 素模色：墙、转角、屋顶切面和底面 |
| `clay.roof` | 否 | 屋顶的素模色，默认是 `clay.wall` 稍暗一点（线性光 × 0.93） |
| `clay.hatch_shade` | 否 | 斜纹的明暗：素模色 × 这个数（线性光），0.5–0.92，默认 0.84。墙上的斜纹色是 `clay.wall` × 它，屋顶上的是 `clay.roof` × 它 |
| `outline` | 是 | `null` 表示不要描边；否则 `{"color", "width_px", "silhouette_color"?, "crease_color"?, "crease_width_px"?}`：剪影宽 `width_px`（CSS 像素），折痕线默认是它的 0.7 倍（至少 1 px），两者颜色默认都是 `color`。地址里的 `outline=<px>` 会覆盖宽度 |
| `toon.steps` | 是 | 卡通明暗的档位，2–6 个递增的亮度，最后一个必须是 1 |
| `lights.hemisphere` | 是 | `{"sky", "ground", "intensity"}` 半球光 |
| `lights.sun` | 是 | `{"color", "intensity"}` 主光 |
| `background` | 是 | `{"type": "solid", "color"}` 或 `{"type": "gradient", "stops": [{"color", "at"}, …]}`（自上而下，`at` 从 0 到 1） |
| `ground` | 是 | `{"color", "rim"}` 地面圆盘和它的边 |
| `gradient` | 否 | `null`，或 `{"top", "bottom", "strength"}`：楼身从下到上乘一层渐变色调（低多边形渐变的效果），`strength` 0–1 |

D29 去掉了上色时代的字段：`palette`（调色板规则和颜色）、`shade`（贴花描边暗色）、`locked_frame`（待解锁墙上的虚线框）、`clay.hatch`（贴图里的素模斜纹色）、`clay.face`（没有贴图的整面素模墙，现在就是 `clay.wall`）。还带着这些字段的旧画风会被当成写错的字段拒绝，查看器退回默认画风。

**默认画风的一个历史包袱**：原来的查看器把剪影色多做了一次颜色空间转换，剪影线显示成 #070608，而折痕线是墨色 #2d2a32。`default.json` 保留了这个剪影色。

## 4. 校验器 `validateTheme`

1. **斜纹要看得见**：墙上的斜纹和 `clay.wall`、屋顶上的斜纹和 `clay.roof`，CIEDE2000 色差都要 ≥ **3**（所以 `hatch_shade` ≤ 0.92；暗的画风在投影里还要更低，`dusk` 用 0.78）。屋顶或墙近于纯黑（例如 #0a0a0a）时斜纹差不到 0.2，会被拒绝。
   - 这个比较按设定的颜色做一遍，再在查看器实际渲染的每种光照下各做一遍（`lightConditions()`，和 `web/stylized.js` 用的 three.js r160 卡通材质同一个算法）：一个面受的光 =（半球光 + 主光 × 明暗档）÷ π，再乘渐变色调；素模色和斜纹色乘上同一个光，按帧缓冲那样在 1 处截断，再比色差。具体取样：
     - **半球光的天空色和地面色都算**：竖直的墙一半天空一半地面，平屋顶只有天空，陡的斜屋顶（法线朝上分量 0.5）在中间；
     - **主光乘每一档明暗**（面朝哪边决定落在哪一档，所以每档都算），再加上**投影里**（被别的体块挡住：只有半球光）；
     - **按绝对亮度算**，不先归一化：光太强时斜纹和底色会一起截成白色（例如把 `storybook` 的光调到半球 4、主光 5，差 0），会被拒绝；
     - 有渐变时，在渐变底部、中部、顶部各算一遍（例如 `dusk` 的 `hatch_shade` 改成 0.85，按设定颜色看得见，但在投影里、渐变底部只差 2.3，会被拒绝）。
2. **格式**：字段类型和范围；不认识的字段（多半是打错字，或上色时代的旧字段）直接报错，不会悄悄用默认值；`name` 和 `description` 是一行中文，`en.name` 和 `en.description` 是一行英文（D32）。校验器自己的报错信息是英文的技术说明，不翻译。

画风改不了的东西：形状、来源卡片、立面起伏。这些都来自 GLB，画风只决定它们用什么颜色、什么光影画出来。

## 5. 四个参考画风

都是我们自己的配色，没有用任何品牌的色值、标志、字体或素材；描述只说类型。

英文名称（`en.name`）：`default` Bright flat、`storybook` Storybook pastel、`dusk` Dusk gradient、`blueprint` Blueprint。

| id | 名称 | 类型 | 怎么做的 | 斜纹最小 ΔE00（在哪） |
|---|---|---|---|---|
| `default` | 明快扁平 | 明亮扁平色 + 粗描边 | 原来的外观，素模是浅蓝灰 | 3.8（投影里） |
| `storybook` | 绘本粉彩 | 柔和粉彩绘本插画 | 细暖棕描边 1.4 px；三档明暗拉近（0.72 / 0.88 / 1）；暖纸色背景；素模是淡粉紫 | 3.3（明暗档 0.72） |
| `dusk` | 黄昏渐变 | 渐变低多边形 | 暖色天光配冷紫色地面；楼身下紫上暖的渐变色调；无描边；四档明暗（0.32 / 0.55 / 0.78 / 1）；黄昏天空渐变；素模是淡薄荷绿 | 3.3（投影里、渐变底部） |
| `blueprint` | 蓝图线稿 | 蓝色图纸上的线稿 | 描边线是白色；明暗几乎拉平；纯色蓝底；素模是深蓝灰的图纸 | 3.3（投影里） |

注意：`blueprint` 画风和决定 D6 的"蓝图态"（只有 Commons 照片时的开放影像预览，是产品状态，不计入玩法）长得像，但不是一回事。如果两者都上线，要让人一眼分得开，例如蓝图态的模型不提供 `blueprint` 画风，或者给蓝图态加单独的标记。

## 7. 限制

- 画风只换颜色和光影，不换形状语言：圆角、描边画在哪，都由风格化作业和查看器决定。
- 校验按取样算光照（第 4 节）：墙、陡斜屋顶、平屋顶三种朝向，投影里和每一档明暗，渐变的底、中、顶。取样点之间的情况不单独算：阴影的软边（主光只挡掉一部分）、别的屋顶坡度、渐变的其他高度。
- 下拉框只列 `index.json` 里的画风；没列进去的画风用地址参数 `theme=<id>` 也能打开。
